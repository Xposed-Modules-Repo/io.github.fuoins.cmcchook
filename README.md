# cmcc-hook

中国移动 App（包名 `com.greenpoint.android.mc10086.activity`）的 Xposed/LSPosed 模块，用于自动完成签到、福利中心与权益任务，并提供优惠券核销验证码自动读取、多账号隔离和请求抓包诊断等辅助功能。

- **模块包名**：`io.github.fuoins.cmcchook`
- **源码仓库**：https://github.com/fuoins/cmcc-hook-src
- **支持/反馈**：https://github.com/fuoins/cmcc-hook

## 主要功能

- 一键签到、福利任务、权益任务、周三/周六等周期性活动
- 优惠券核销短信验证码自动读取（含系统电话进程框架层通道）
- 多账号按 UID 隔离，任务状态与凭证互不干扰
- 请求抓包与诊断日志，便于排查任务执行情况
- 脚本凭证提取（供外部签到脚本使用）

## 安装与启用

1. 本模块为全新包名，**与早期 `com.cmcchook` 版本不是同一个应用，无法覆盖安装**：请先卸载旧版再安装。
2. 在 LSPosed 中启用本模块，作用域至少勾选「中国移动」。
3. 若需短信验证码自动读取，另需勾选「电话服务」`com.android.phone` 及小米的 `com.xiaomi.phone`（系统应用，需先在 LSPosed 打开「显示系统应用」），并重启手机；同时在系统设置里关闭「验证码安全保护」、给中国移动放行「通知类短信」。
4. 升级后建议强停中国移动或重启一次，并在日志头确认版本号是新的。
